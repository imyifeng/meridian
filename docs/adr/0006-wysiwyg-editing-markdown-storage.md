# WYSIWYG 编辑体验 + Markdown 存储

产品面向大众：用户不该看到 `**`、`#` 这类语法符号。因此客户端编辑器采用生产级 WYSIWYG 组件（AppFlowy Editor / Super Editor 一类）：输入 Markdown 快捷方式或点工具栏即得样式，语法符号不出现；保存时序列化为干净 Markdown 落盘。编辑体验与存储格式分离，两头兼顾——Markdown 保证数据可迁移（随时导出 .md）与未来 AI 的自然读写，WYSIWYG 保证 Word 式手感。曾认真考虑过放弃 Markdown：改用私有 JSON 存储（数据被应用格式锁死）或纯文本（失去格式化，与需求矛盾），均否决。

v1 格式集定死：标题 H1–H3、加粗、斜体、删除线、行内代码、代码块、有序/无序列表、待办勾选、引用、链接。超出格式集的 Markdown（如表格）只读展示，不承诺可编辑；往返转换仅在格式集内承诺无损。
