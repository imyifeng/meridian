# 备忘录正文一律纯文本

取代 ADR-0006（WYSIWYG 编辑、Markdown 存储）。经 V1 实际使用评估，备忘录是临时记事而非笔记，格式化渲染与 WYSIWYG 编辑对它价值很低，却让客户端背上了精确锁版的 super_editor 依赖与整套 Markdown 编解码管线。V2 起备忘录的标题与正文一律纯文本：编辑用普通文本框，查看与列表摘要直接展示、截断正文，super_editor 与格式集白名单整体移除。不做数据迁移——项目从未投入真实使用，存量只有测试数据；旧正文里的 Markdown 符号原样按字面显示，新备忘录自然不会产生符号。0006 的核心论据"Markdown 保证可迁移（导出 .md）与 AI 的自然读写"随之失效：纯文本本身就是最可迁移的格式，对 AI 反而更友好。
